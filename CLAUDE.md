# EIC Chula website

The website and admin panel of the Engineering Innovator Club (EIC), Chulalongkorn University.
SvelteKit 3 on Vercel, Postgres, Auth and Storage on Supabase, schema in Drizzle.

## Commands

Use Node 24 (`engines` is enforced) and pnpm.

```bash
pnpm dev            # dev server
pnpm check          # svelte-kit sync + svelte-check (must be 0 errors)
pnpm build          # production build (adapter-vercel)
pnpm db:generate    # schema.ts -> new SQL migration in supabase/migrations
pnpm db:migrate     # apply migrations to DATABASE_URL
pnpm db:seed        # load supabase/seed.sql into DATABASE_URL (first-time content)
pnpm preview:vercel # preview the build the way Vercel runs it (no require() of ES modules)
pnpm images:resize  # smaller copies of new photos in static/images (--force, --check)
```

Vercel's function runtime cannot `require()` an ES module, which Node 24 otherwise allows. A
CommonJS package that requires an ESM-only dependency works locally and crashes on Vercel with
`ERR_REQUIRE_ESM` (this happened with `sanitize-html` 2.18 + `htmlparser2` 12, so `sanitize-html` is
pinned to 2.17.5). After adding a server dependency, run `pnpm build && pnpm preview:vercel` and
load the pages that use it.

## SvelteKit 3: what differs from Kit 2

- `$lib` is gone. Import with `#lib/...` and **always write the extension**:
  `#lib/server/db/index.ts`, `#lib/utils.js`, `#lib/components/site/Nav.svelte`.
- No `svelte.config.js`. Kit options go in `sveltekit({...})` in `vite.config.ts`.
- Env vars are declared in `src/env.ts` and imported from `$app/env/private`. They are all
  optional here so builds work without secrets. `$app/environment` became `$app/env`.
- Hook types (`Handle`, `sequence`, ...) come from `@sveltejs/kit/hooks`.
- `redirect()` and `error()` throw (never `return` them, never catch them). `fail()` is returned.
  External redirects need `redirect(303, url, { external: true })`.
- `$app/stores` throws at runtime: use `$app/state`. `invalidateAll()` became `refreshAll()`.
- `asset('x.png')` takes no leading slash. Plain `href="/about"` links are fine.
- Remote functions are experimental and are **not** used. Use `load` + form actions + `use:enhance`.
- Server-only code: anything in a `/server/` folder or named `*.server.*`.

## Layout of the code

- `src/lib/server/db/schema.ts`: the database schema, the single source of truth. Every table has
  RLS enabled with no policies: the app connects directly as the database owner, so Supabase's
  public Data API can't touch the tables. After changing it run `pnpm db:generate` and commit the
  new migration. Never edit a generated migration; write a custom one with
  `pnpm exec drizzle-kit generate --custom --name=xyz`.
- `src/lib/content/sections.ts`: editable page sections (fields + designed default copy).
  Public pages read them through `getPageSections(page)` from `#lib/server/content.ts`; the admin
  Pages editor renders forms from the same field definitions.
- `src/lib/server/`: `auth.ts` (editors, `requireEditor`, `requireOwner`), `activity.ts`
  (`logActivity` for the dashboard feed), `storage.ts` (the `media` bucket; the browser PUTs
  uploads straight to Storage with a signed URL from `/admin/api/upload`, then calls
  `/admin/api/upload/complete`), `markdown.ts` (post rendering + sanitising;
  `markdown/reading.ts` counts reading time without loading Shiki or KaTeX), `supabase.ts`
  (auth client, admin client), `rate-limit.ts` (limits shared by all instances, in the
  `rate_limits` table), `secret.ts` (keys derived from the server secret for signing and
  keyed hashes), `queries/` (site and admin reads).
- `src/hooks.server.ts`: security headers, the public cache header, per-request Supabase auth
  client, verified user, admin guard (by route id, so encoded paths are guarded too).
- `src/lib/image.ts`: `optimizedSrc()` and `srcset()` for every photo. Media bucket photos go
  through `/_vercel/image`; site photos in `static/images` use their pre-made copies.
- `src/lib/components/ui/`: shadcn-svelte components (generated by the CLI, themed through the CSS
  variables in `src/routes/layout.css`). Add EIC variants to them when needed; keep their structure.
  Add more with `pnpm dlx shadcn-svelte@latest add <name>`.
- `src/lib/components/site/`: public site components (Nav, Footer, TitleBlock, Note, ImageSlot...).
- **Prefer shadcn-svelte everywhere** (admin and public site) for anything shadcn has: buttons, badges,
  inputs, textareas, selects, checkboxes, switches, toggle groups, tabs, dialogs, sheets, dropdowns,
  tooltips, toasts, tables, cards. Extend them with EIC variants (you own their code: add variants in
  the component's `tailwind-variants` definition) instead of writing look-alikes. Build custom
  components only for what shadcn doesn't have (TitleBlock, Note, ImageSlot, HeroBand, the timeline).
- `src/lib/components/admin/`: admin building blocks.
- `src/routes/(site)/`: public pages. `src/routes/admin/`: admin panel. `src/routes/auth/`: sign in callbacks.

## Caching, CSP and limits

- Public pages are shared by Vercel's CDN for 60 s (`publicCache` in `hooks.server.ts`). A
  `(site)` load must never read `locals.user`, `locals.editor`, cookies or anything else per
  visitor, or one visitor's page is served to everyone. Editors' changes show within a minute.
- The Content-Security-Policy is in `vite.config.ts` (`csp`, hash mode). A new embed provider
  needs its player origin in `frame-src` (plus `markdown/embeds.ts`, `markdown/sanitize.ts`
  and `site/post-enhance.ts`); an outside script, style or font needs `script-src`,
  `style-src` or `font-src`. No inline event handlers. A plain `<script>` in `app.html` is
  hashed by the build. Check the console for CSP errors on `pnpm build && pnpm preview:vercel`.
- A new public form or endpoint that sends email or writes rows gets a limit:
  `hit(await limitKey('scope', value), { max, windowSeconds })` from
  `#lib/server/rate-limit.ts`. For a client address use `clientLimitKey('scope', ip)`
  instead, which counts an IPv6 /64 as one client; `limitKey` is for other values such as
  emails. Never store raw IPs or emails for it.
- After adding or replacing a photo in `static/images/archive` or `static/images/people`, run
  `pnpm images:resize` (`--force` after a replace) and commit the copies and
  `src/lib/image.ts`.

## Admin panel rules

- The hook refuses non-GET requests to `/admin/**` without an invited editor, and the admin layout
  redirects page loads to `/admin/login`. Still call `requireEditor(locals)` (or `requireOwner`) at
  the top of every admin action and load.
- Validate every input on the server (valibot or explicit checks). Return `fail(400, {...})` with
  field messages; show success and errors with toasts (`svelte-sonner`).
- Call `logActivity(editor, {...})` after every create, update and delete.
- Admin UI is built from shadcn-svelte parts themed with the EIC tokens: less decoration than the
  site (no graph paper or notes), `surface-000` sidebar, `surface-200` panels, 44px controls,
  dashed drop zones for uploads, green "Published" and grey "Draft" badges.

## Design system (public site)

Dark only. "Simple, with a drafting table's craft." Tokens are Tailwind utilities:

- Colour: `bg-surface-000|100|200|300`, `text-ink`, `text-ink-muted`, `border-line`,
  `border-line-strong`, `bg-brand` (EIC red #D7262C), `text-brand-text` (red as text, #FF6A6E),
  `text-on-brand`, `text-success`. One red moment per region.
- Type: `font-display` (Space Grotesk, headings, weight 600, tight tracking), `font-sans` (Inter,
  body 16/26), `font-mono` (JetBrains Mono), `font-hand` (Caveat, handwritten notes only).
  `text-label` = mono eyebrow (12/16, uppercase, 0.08em). `text-spec` = mono 13/20.
- Layout: `site-container` (1200px column, 32px gutters, 16px on phones). Sections pad 96px
  desktop / 64px mobile; every section opens with a mono label and a heading.
- Shape: `rounded-xs` 2px tags, `rounded-sm` 6px controls, `rounded-lg` 10px cards and photos,
  `rounded-full` avatars and dots. Hairline `border-line` borders, no shadows, glows or gradients.
- Drafting details, hero bands only: `bg-graph-paper`, `ruler-strip`, a faint construction circle,
  the TitleBlock. Image placeholders use `crop-marks`. At most one handwritten Note per section.
- Copy: plain, specific, sentence case. **No dashes as punctuation**: use a full stop or comma.
  Walkie (no "the"), RoboCup@Home, EIC Chula.
- Accessibility: real `<a>`/`<button>`/`<label>`, visible focus ring, 44px touch targets,
  text contrast 4.5:1, `alt` on every image, decorative SVG `aria-hidden="true"`.
